# Security Policy

## Supported Versions

Security fixes and updates are actively maintained on the latest commit of the `main` branch.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |
| Older releases   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do **not** disclose it publicly via GitHub issues or discussions.

Instead, please report it privately:

1. **GitHub Security Advisory:** Submit a private advisory report directly via GitHub Security Advisories if available on the repository.
2. **Direct Contact:** Email the maintainer directly at **ajayelika99511@gmail.com** with the subject line:
   `[SECURITY] Vulnerability Report - Portfolio`

### What to include in your report:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept (PoC).
- Potential impact and affected components/routes.
- Any suggested remediations or mitigations.

### Response Timeline
- **Initial Response:** Within 48 hours of receipt.
- **Triage & Assessment:** Within 5 business days.
- **Fix & Public Notice:** As soon as feasible depending on severity.
