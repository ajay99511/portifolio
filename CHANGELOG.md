## [0.1.0] - 2026-06-27

### Added
- **Core Architecture:** Built portfolio using Next.js 16 (App Router), React 19, and Tailwind CSS v4.
- **Interactive Project Demos:**
  - FastBeat (Android Media3 audio player replica)
  - Chronos Planner (productivity & calendar suite)
  - DayVault (Flutter architecture refactor replica)
  - ICM Fraud Detection (ML analytics pipeline)
  - DL Algorithms (Deep learning interactive models)
  - RepoPulse, GitScripe, DbPred, SMPred, SocialNetwork, PersonalAssist, and MdExplorer.
- **Content System:** Static Markdown blog engine with metadata extraction, syntax highlighting, reading-time estimates, and table-of-contents support.
- **UI & UX:** Custom interactive cursor, dynamic theme switching (Dark/Light) via `next-themes`, responsive mobile navigation menu, and accessible focus trapping.
- **Quality Assurance:** Comprehensive Vitest unit tests, React Testing Library component integration, and fast-check property-based testing.
- **Analytics:** Integrated `@vercel/analytics` and `@vercel/speed-insights`.
